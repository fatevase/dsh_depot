实施取舍及代价

  • Ruling: Native worktree failed because the original checkout has no initial main commit — cloned the user-designated public distribution repository into ignored .runtime/dsh-depot-manager and created an isolated codex branch — cost: this checkout is not a managed app worktree, so its paths are explicitly recorded.
  • Ruling: Baseline network isolation needs an unsandboxed test process for local NIC listener; original baseline cases passed there. The asynchronous baseline discovered new RED tests during creation; their three failures were expected and separately verified GREEN. Runtime metadata now requires source=host to reject toolkit substitution.
  • Task 5: Ruling: rc.2 has no verified cross-exit worker lifetime. Handoff persists an owner-bound job and returns RESUME_FROM_SCRIPT; no background auto-resume is enabled — avoids assuming Electron/service child survival — cost: users must run the external script after exit. Consequently no unsupported worker lifetime is promoted by a parent-exit simulation.
  • Task 4: Ruling: full private plans and snapshot paths stay in local 0600 receipts; display/API serializers exclude them — immutable execution context cannot be supplied by a browser — cost: local-state corruption remains an explicit recovery error.
  • Task 6: Ruling: Windows uses a single .tgz envelope extractable by Windows' tar.exe; no ZIP runtime dependency is introduced. Official Node upstream remains win-x64.zip — reduces archive-format implementation surface — cost: Windows guide must include tar extraction rather than claiming Explorer ZIP support.
  • Task 7: Ruling: use the verified public Connection Fetch registry for authenticated same-origin Svelte management at /api/depot/manager, and public index-inject for its entry link. The frozen stock Host lacks the newer UI-slot package; no fabricated slot API or third-party sidebar dependency — cost: Web manager opens a dedicated DSH page instead of an in-layout central slot. Desktop remains gated.
  • Final: Ruling: discovery may display metadata for an elevated or foreign-owned profile but disables all write capabilities; the adapter rechecks identity immediately before writes — avoids treating an inspectable installation as nonexistent while preserving ordinary-user ownership — cost: administrator-owned profiles require initialization/ownership correction by their owner outside this tool.
  • Final: Ruling: completed recovery-point retention is bounded to the latest three points; restored failures may remain for 30 days and unfinished points never expire. Installed archive references and current stores are protected — prevents unbounded ordinary-use disk growth — cost: an older successful point can be removed before 30 days.
  • Final: Ruling: native Windows/Linux/Fedora/SSH/double-click/full-Node validation remains unverified; no mock or build green flag promotes it. Official Node macOS archive download reset/timed out, so no local full bundle is claimed — cost: first-installer release remains blocked until exact native artifacts are accepted.
  • Final: Ruling: rc.2 manual continuation, Desktop write gating, authenticated dedicated Web page, Windows tgz extraction, unchanged website styling, and excluded agent/source-build/auto-update/kernel work remain as specified or previously ledgered — cost: these are explicit first-version limits, not implied support.
