# DSH 离线插件管理器

在当前 DSH Web 环境中导入已构建的 `.tgz` 或成品目录，检查依赖与平台后保存安装计划；退出 DSH 后运行脚本继续。

管理页面显示安装预览、插件列表与任务记录。卸载默认保留业务数据与配置，内置项和管理器本身受保护。管理器更新或移除请在退出 DSH 后从外部脚本进行。

首次使用需要已有的 DSH。完整安装包附带独立 Node，轻量包需要 Node `^22.19.0 || >=24.0.0`。不需要管理员权限，不会下载运行依赖，不执行包的安装脚本。原生模块仍须适配目标宿主。

“等待加载”表示文件操作已完成；只有宿主观察到相应插件实际加载后才显示“已加载”。常规安装直接调用对应 DSH，不遍历或备份整个已安装依赖目录，不自动回滚。失败时查看任务错误和日志，修正后重装成品或先前版本；旧版已创建的恢复点仍可从外部脚本恢复。

当前版本针对 DSH `0.2.0-rc.2` Web 公开接口开发。官方桌面宿主尚未验证写入能力时会阻止修改。各平台实际可用范围以分发报告为准。
