# DSH 离线插件管理器

在 DSH 的「设置 → 本地插件」中拖入或选择已构建的 `.tgz`、成品目录，检查后调用当前宿主自带的安装后端；安装完成后重启 DSH。

设置页上方提供拖入安装，下方显示插件版本、状态和卸载操作。检查信息在安装确认窗口内展开，操作记录默认折叠。页面继承 DSH Desktop 的 `--dsw-*` 主题变量，跟随宿主浅色、深色切换。卸载默认保留业务数据与配置，内置项和管理器本身受保护。管理器更新或移除请从外部脚本进行，完成后重启 DSH。

首次使用需要已有的 DSH。完整安装包附带独立 Node，轻量包需要 Node `^22.19.0 || >=24.0.0`。不需要管理员权限，不会下载运行依赖，不执行包的安装脚本。原生模块仍须适配目标宿主。

“等待加载”表示文件操作已完成；只有宿主观察到相应插件实际加载后才显示“已加载”。常规安装直接调用对应 DSH，不遍历或备份整个已安装依赖目录，不自动回滚。失败时查看任务错误和日志，修正后重装成品或先前版本；旧版已创建的恢复点仍可从外部脚本恢复。

当前适配 DSH `0.2.0-rc.2` 和 macOS DSH Desktop `0.12.0`。Desktop 安装调用应用自带的分代后端与 pnpm，不重新解析其他插件的依赖。未适配的宿主会阻止修改，各平台实际可用范围以分发报告为准。
