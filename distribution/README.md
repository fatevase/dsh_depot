# 插件分发流水线

按人工维护的构建配置，重复执行以下流程：

1. 检查已收录仓库的新版本，将新发现插件加入候选清单。
2. 比较宿主兼容性、源码、构建配置、依赖锁与目标平台，无变化时跳过。
3. 在对应系统构建，打包完整运行依赖。
4. 使用原版 DSH，在空缓存和网络隔离下验证安装、启动与插件加载。
5. 发布安装包、校验和与报告，更新公开目录。

普通插件的构建配置位于 `recipes/`。`manager/` 仅保留配套管理器的 CI 验证和发布编排，管理器源码位于 [plugins/dsh-depot-manager](../plugins/dsh-depot-manager/)，网站位于 [web](../web/)。

操作步骤见[分发维护说明](MAINTAINING.md)，工作区安装、模块命令和独立工作流见[根维护说明](../MAINTAINING.md)。
